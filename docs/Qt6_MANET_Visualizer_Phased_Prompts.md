# Qt 6 MANET Visualizer --- AI Coding Agent Instructions

## Project Overview

I am building a **MANET (Mobile Ad Hoc Network) Visualizer** using **Qt
6 and C++**.

The MANET simulation is generated using **NS-3**. The NS-3 simulation
produces CSV files containing simulation data. My Qt application must
read these CSV files and visualize the MANET simulation.

The project must be implemented **phase by phase**. Do not implement
future phases until I explicitly request them.

# Important Development Rule

Always start by inspecting the actual CSV.

For every new CSV:

1.  Identify the header.
2.  Identify all columns.
3.  Identify the units.
4.  Identify timestamp format.
5.  Identify node IDs.
6.  Identify coordinate system.
7.  Identify whether rows represent individual events or periodic
    snapshots.
8.  Only then implement the corresponding CSV parser.

**Never invent data that is not present in the CSV.**
